在实现和测试过程中，我们发现并修正了关键的理论错误，确保了理论与有限状态空间的实际约束一致。

### T10-2 无限回归定理的修正

**原始错误假设**：
- 声称collapse算子是压缩映射（压缩因子1/φ）
- 基于Banach不动点定理预期收敛到唯一不动点

**发现的问题**：
- φ > 1，所以1/φ < 1，但collapse算子实际上是扩展的
- 有限状态空间中不存在严格的不动点收敛

**理论修正**：
- 从"收敛到不动点"改为"进入周期轨道"
- 引入Fibonacci界限的预周期长度分析
- 将"φ-平衡态"重新定义为"周期轨道"

### T10-3 自相似性定理的适应

**原始假设**：
- 使用连续系统的Hausdorff维数公式 D_H = log(p)/log(φ)

**实际约束**：
- 有限状态空间限制了轨道长度
- 需要有效维数而非几何维数

**理论调整**：
- 引入有效维数 D_eff = log(N_patterns)/log(L_scale)
- 调整相似度阈值以适应离散系统
- 重新定义多尺度结构的检测方法
